# Apex Financial Services — Identity and Access Management (IAM)

## Project Overview

This directory contains practical Identity and Access Management (IAM) exercises conducted as part of the Apex Financial Services (AFS) Enterprise Cybersecurity Lab.

The lab simulates an enterprise Active Directory environment for a fictional financial services organization.

**Organization:** Apex Financial Services (AFS)  
**Domain:** `corp.lab`  
**Domain Controller:** AD-DC01  
**Domain Workstation:** CLIENT01  
**Environment:** Isolated VirtualBox lab

## Objectives

- Active Directory organizational structure and administration.
- Identity provisioning and lifecycle management.
- Role-Based Access Control (RBAC).
- Group-based access management.
- Least privilege and separation of duties.
- Privileged access management.
- NTFS and shared-folder permissions.
- Group Policy and identity security.
- Access reviews and account auditing.

## Documentation Standard

Every exercise will document:

1. Objective and purpose.
2. Scope and authorization.
3. Prerequisites.
4. Initial environment state.
5. Step-by-step methodology.
6. Commands and configuration changes.
7. Expected results.
8. Actual results and evidence.
9. Verification procedures.
10. Security analysis.
11. Limitations.
12. Cleanup and rollback.
13. Conclusion and final status.

## Lab Security Principles

- Use fictional identities and training data.
- Preserve existing virtual machines and directory objects.
- Never expose passwords, API keys or other secrets.
- Apply least privilege.
- Verify configuration changes before proceeding.
- Record actual results rather than assumed outcomes.
- Keep all testing within the authorized lab environment.
